# Finance Tracker

A small personal finance app: log money in (tuition, carpool, side gigs) and money out (coffee, lunch, clothes…), see each month at a glance, and track a savings goal in the **iPhone Jar** tab.

It is a plain web app (`index.html`), so it runs in any browser and can be added to a phone's home screen. It works offline.

## Your data

Everything is stored **only in the browser on your phone**. Nothing is sent anywhere. Use **Backup → Copy backup** now and then and keep the text somewhere safe (Notes, WhatsApp to yourself). **Restore from backup** brings it back on a new phone.

## Files

- `index.html` — the whole app
- `manifest.webmanifest` — app name, icon and colours for the home screen
- `sw.js` — lets the app open offline
- `icons/` — home-screen icons
